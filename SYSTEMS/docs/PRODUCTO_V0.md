# Producto v0 — Definición

**Estado:** Borrador inicial (Día 15)

## ¿Qué es DSR Labs v0?
Un sistema que permite a un usuario ejecutar inferencias de modelos de lenguaje en hardware propio de forma auditada y controlada.

## Alcance Mínimo (MVP v0)
1. **Interfaz CLI**: Para enviar prompts.
2. **Registro de Procesos**: Cada inferencia queda guardada localmente.
3. **Control de Flujo**: Validación básica del input antes de enviarlo al modelo local.

## Lo que NO es (aún)
- No es multi-usuario.
- No tiene interfaz web.
- No gestiona pagos.

El foco es el **proceso técnico**, no la experiencia de consumo masivo.
