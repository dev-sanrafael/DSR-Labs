# Ajuste Producto v0.1

**Fecha:** Día 20

## Feedback recibido:
- La configuración de Proxmox es una barrera para la mayoría.
- El orquestador CLI es potente pero intimida.

## Ajustes realizados:
1. **Documentación de Infra**: Vamos a crear guías paso a paso para desplegar el entorno en Proxmox usando scripts automáticos.
2. **Simplificación del Flujo**: El orquestador ahora aceptará archivos de configuración `.env` para evitar pasar tantos parámetros por CLI.

**Iteración > Perfección.**
