# Token v0 — Concepto Inicial

El token de DSR Labs no nace para el trading, sino para la **orquestación**.

## Utilidad Propuesta:
- **Prioridad**: Los poseedores del token tienen prioridad en las colas de inferencia.
- **Gobernanza Técnica**: Decisiones sobre qué modelos agregar al cluster Proxmox.
- **Staking de Recursos**: En el futuro, permitir que otros aporten hardware al cluster.

## Reglas Base:
- No habrá venta masiva sin un sistema funcional.
- El valor está atado a la capacidad de cómputo real disponible en el laboratorio.

**IA Soberana = Cómputo Real.**
