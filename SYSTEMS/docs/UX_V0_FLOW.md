# UX v0 — Flujo de Usuario Inicial

El objetivo de la UX en esta etapa es la **claridad técnica**.

## El camino del dato:
1. **Entrada**: El usuario escribe su petición en la terminal.
2. **Validación**: El sistema muestra: `[VALIDANDO...]`
3. **Ejecución**: El sistema muestra: `[LLAMANDO A OLLAMA...]`
4. **Salida**: La respuesta se imprime línea a línea.
5. **Log**: Se muestra la ruta del archivo donde quedó el registro.

## Puntos de fricción actuales:
- Dependencia total de la terminal.
- Tiempo de espera sin barra de progreso real (solo logs).

*Nota: Se prioriza la información técnica sobre la estética.*
